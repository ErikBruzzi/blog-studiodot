Um erro comum de quem está contratando um site pela primeira vez é pedir "algo bonito e moderno" sem pensar em quem vai visitar aquele site. O problema é que "bonito" muda completamente dependendo do público.

Um site bonito para uma marca de suplementos fitness pode parecer pouco sério para um escritório de advocacia — e o contrário também é verdade. Aqui vão três exemplos reais que mostram como o estilo visual muda de acordo com o objetivo.

## 1. Quando o objetivo é credibilidade: escritório de advocacia

![Site institucional para escritório de advocacia](/work-advocacia.png)

Para negócios que vivem de confiança — advocacia, medicina, consultoria — o design precisa comunicar solidez. Paleta sóbria (aqui, azul-marinho e dourado), tipografia serifada, bastante espaço em branco. Nada de excesso: cada elemento visual existe pra reforçar "isso aqui é sério".

## 2. Quando o objetivo é conversão imediata: landing page fitness

![Landing page de lançamento de produto fitness](/work-fitness.png)

Aqui a lógica se inverte. O objetivo não é parecer "confiável e tradicional" — é gerar energia e urgência. Preto e verde-limão, tipografia bold, linguagem direta. Uma landing page de conversão tem um único trabalho: levar a pessoa até o botão de ação o mais rápido possível.

## 3. Quando o objetivo é uso no dia a dia: interface de app

![Interface mobile de aplicativo de agendamentos](/work-agendamento.png)

Interfaces de aplicativo seguem uma lógica diferente dos dois casos acima: não é sobre impressionar, é sobre ser invisível. Cores suaves, hierarquia visual clara, zero fricção. O usuário não deveria "notar" o design — deveria simplesmente conseguir fazer o que veio fazer.

## O ponto em comum entre os três

Nenhum desses estilos é "melhor" que o outro — cada um é certo pro contexto em que foi pensado. O trabalho de definir o estilo certo começa antes do design, entendendo quem é o público e o que ele precisa sentir na primeira visita.

É por isso que, antes de abrir qualquer ferramenta de design, a primeira etapa do [meu processo](/processo.html) é sempre entender o negócio e o público — não pular direto pra estética.
